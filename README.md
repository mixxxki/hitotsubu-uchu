# ひとつぶ宇宙

スマホ向けのインクリメンタル（放置・クリッカー）ゲームです。
中央の「核」をタップして粒子を集め、生成装置を増やし、ビッグバン・挑戦・次元上昇で層を重ねて宇宙を広げていきます。

- Vite + TypeScript（フレームワークなし）
- PWA 対応（一度開けばオフラインでも遊べる。ホーム画面に追加可）
- 巨大数は [break_eternity.js](https://github.com/Patashu/break_eternity.js)
- ロジック 20 tick/秒、描画は `requestAnimationFrame`

## 起動方法

Node.js 20 以上（推奨 22）が必要です。Windows の場合は PowerShell かコマンドプロンプトで実行します。

```bash
npm install
```

```bash
npm run dev
```

ブラウザで `http://localhost:5173/` を開きます。

本番ビルドと確認:

```bash
npm run build
```

```bash
npm run preview
```

`dist/` に出力されたファイルを任意の静的ホスティング（GitHub Pages など）に置けば、そのまま PWA として動きます。

## スマホでの確認方法（同じ Wi-Fi）

1. PC とスマホを同じ Wi-Fi に接続する
2. PC で次を実行する

   ```bash
   npm run dev -- --host
   ```

3. ターミナルに表示される `Network: http://192.168.x.x:5173/` の URL をスマホのブラウザで開く
4. 開けないときは Windows のファイアウォールで Node.js の「プライベート ネットワーク」での通信を許可する（初回起動時に出るダイアログで「許可」を選ぶ）

※ Service Worker（オフライン動作・ホーム画面追加）は `localhost` か HTTPS でのみ有効になるため、LAN 経由の `http://192.168...` では無効です。オフライン動作を確かめるときは `npm run build && npm run preview` を PC で開くか、HTTPS のホスティングに置いてください。

## 遊び方

| 層 | 内容 |
| --- | --- |
| 粒子 | 核をタップ／生成装置8種（塵・小石・岩塊・月・惑星・恒星・星団・銀河）。25・50・100台、以降100台ごとに生産×2 |
| 強化 | 120個をマス目で表示（購入済み・購入可・解放済み・未解放）。単体倍率・相乗効果・タップ・全体倍率・流れ星・実績連動 |
| 流れ星 | ときどき画面を横切る。タップで一定時間の倍率か、大量の粒子 |
| 実績 | 122個。1個ごとに全体倍率+1% |
| ビッグバン | この周回で粒子 1e15 から実行可。宇宙定数を得て、法則の木（35個＋繰り返し1個、二択あり・振り直し可）に使う。「定数/分」がビッグバンの目安 |
| 挑戦 | 縛り付きの周回12種。法則の木で4つずつ解放。達成で特別な報酬 |
| 次元上昇 | この周回で粒子 1e100 から実行可。ビッグバン層ごとリセットして「次元の欠片」を得る。新系統「次元装置」4種と「次元の刻印」が解放 |
| 自動化 | 自動タップ（BB1回）→ 装置の自動購入（BB3回）→ 強化の自動購入（BB8回）→ 自動ビッグバン（BB15回・条件指定）→ 次元装置の自動購入（次元上昇1回）→ 自動次元上昇（同5回） |
| 多元宇宙 | 3層目。枠と解放条件（次元の欠片 累計3e15・次元上昇10回）のみ。中身は今後追加 |

- 放置: 最終保存時刻との差分を一括計算（基本24時間まで。法則の木・次元の刻印で延長）。再訪時に「留守中に +◯◯」を表示
- 保存: localStorage に5秒ごと＋画面を離れたとき。設定（右上の歯車）からエクスポート／インポート
- 数字の表記: 設定で `1.23e15` 形式と `1.23Qa`（K/M/B…）形式を切り替え

## ディレクトリ構成

```
src/
  core/          ゲームロジック（DOM に依存しない）
    state.ts       セーブされる状態の型と初期値
    formulas.ts    倍率・価格・獲得量の計算（純粋関数）
    actions.ts     購入・ビッグバン・挑戦・次元上昇・多元化などの操作
    tick.ts        1 tick の進行（生産・自動化・流れ星）
    achievements.ts 実績判定
    game.ts        ゲームループ・放置計算・自動保存
    save.ts        保存／エクスポート／インポート
    events.ts      コア→UI への通知
  data/          数値バランス（調整はここ）
  ui/            画面（DOM 操作のみ。計算は core を呼ぶ）
    views/         各タブ
scripts/sim.ts   バランス検証用シミュレータ
```

## バランス調整の場所

数値はすべて `src/data/` にまとまっています。

| ファイル | 内容 |
| --- | --- |
| `src/data/balance.ts` | tick 数、自動保存間隔、節目（25/50/100台）と倍率、流れ星の間隔・効果、実績ボーナス、ビッグバン条件と宇宙定数の計算式、次元上昇条件と欠片の計算式、多元宇宙の解放条件、放置上限 |
| `src/data/generators.ts` | 生成装置8種の基本価格・価格増加率・基本生産、次元装置4種 |
| `src/data/upgrades.ts` | 強化120個（価格・効果・解放条件） |
| `src/data/lawTree.ts` | 法則の木（価格・前提・効果・配置）と繰り返し強化 |
| `src/data/challenges.ts` | 挑戦12種（縛り・目標・報酬） |
| `src/data/dimension.ts` | 次元の刻印（欠片で買う永続強化） |
| `src/data/automation.ts` | 自動化の解放条件、自動タップの基本速度 |
| `src/data/achievements.ts` | 実績の一覧と条件 |
| `src/data/multiverse.ts` | 多元宇宙の強化（空）と通貨の計算式。ここに追加していく |

### シミュレータ

「序盤は手でタップし、流れ星を7割拾い、費用対効果の良い順に買う」プレイヤーを想定して、到達時間を出力します。

```bash
npm run sim -- 2
```

引数は時間（h）。`--asc` を付けると初回の次元上昇で止まります（例: `npm run sim -- 400 --asc`）。

現在の目安（休まず最適に遊んだ場合。実際の人はもう少し遅くなる想定）:

- 初購入: 数秒、最初の強化: 30秒前後
- 最初のビッグバン: 約50分（人が遊ぶと1〜2時間）
- 初回の次元上昇: 約5日（挑戦12「真空」が関門）
- 多元宇宙の解放: 約80日（次元上昇後は欠片が少しずつ伸びる）

## 多元宇宙（3層目）を作るとき

- 解放条件: `src/data/balance.ts` の `multiverseReq*`
- 通貨「可能性」の式・強化の一覧: `src/data/multiverse.ts`
- リセット処理: `src/core/actions.ts` の `multiverse()`
- 状態: `src/core/state.ts` の `multiverse`
- 画面: `src/ui/views/cosmos.ts` の `renderMulti()`
